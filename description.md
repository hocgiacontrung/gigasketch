# Bringing Sketches to Life with Generative AI

> **Individual project** · **Deadline: 20 Nov**

## Project Description

Develop a **sketch-to-image generation system** that turns hand-drawn sketches into realistic or visually compelling images using generative AI.

Start from a rough drawing (a futuristic building, a character, a product design, or any creative concept) and generate an image that **preserves the main structure of the sketch** while adding meaningful visual details.

You're encouraged to be creative, experiment with different approaches, and go beyond the basic requirements.

## Technical Requirements

- You may use **existing pretrained models** or experiment with training / fine-tuning.
- Possible technologies: **Stable Diffusion, ControlNet, LoRA**, or other suitable generative models.
- You may use **text prompts** to guide generation (style, materials, lighting, environment, etc.).
- Training from scratch is **not required**.
- The project **must include a technical implementation** — just using an online image-generation interface without building/configuring a pipeline is **not sufficient**.
- Your implementation should show that you **understand how your chosen approach works**.

## Expected Deliverables

| Deliverable | What's expected |
|---|---|
| **Source code** | Shared via GitHub or another accessible repository |
| **Input sketches** | The original sketches used — **at least 3 different sketches** |
| **Generated results** | Generated images shown next to their input sketches; experiment with different prompts/settings |
| **Technical explanation** | Models, tools, and methods used, incl. **how the sketch influences the generated image** |
| **Reproducibility** | Installation instructions, dependencies, model references, main settings |
| **Documentation** | References for all external libraries, models, repos, Hugging Face resources, datasets, sketches, etc. |

## Optional Advanced Challenges (bonus)

- Fine-tuning a pretrained generative model
- A simple user interface or web app
- Deploying the app locally or on a server
- A demonstration video
- A chatbot that accepts a sketch + optional text prompt
- An AI agent automating the whole flow from sketch to final image

## Evaluation Criteria

| Criterion | Weight |
|---|---|
| Technical implementation & understanding | **30%** |
| Quality of results & sketch preservation | **25%** |
| Experimentation & analysis | **20%** |
| Code quality, documentation & reproducibility | **15%** |
| Creativity & originality | **10%** |
| Optional advanced features | Bonus |

## Submission

- A **link to your code repository**
- A **short report (~2–4 pages)** presenting your approach, experiments, and results
- The report must include **clear side-by-side comparisons** of original sketches vs. generated images

## Important Notes

- Individual project — all work must be your own; acknowledge external resources and AI assistance.
- Pretrained models, open-source libraries, and AI coding assistants are allowed, but **you must understand and be able to explain your implementation**.
- Only use sketches/datasets you have permission to use. Don't upload confidential or sensitive info to external services.

Be creative, experiment, and have fun bringing your ideas to life! Good luck! :)
